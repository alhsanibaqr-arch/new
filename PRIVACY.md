# Vardely Privacy Policy

Last updated: 14 October 2026

Vardely is an on-device focus and app-blocking tool. This version stores the selected package names, protection setting, accessibility disclosure choice, and blocked-attempt counts in private app storage on your device.

Vardely's Accessibility Service checks only the package name of the currently opened app to compare it with the block list. It does not retrieve screen content, record keystrokes, capture passwords, or transmit this information to Vardely servers. This version does not include advertising or analytics SDKs.

You can disable the Accessibility Service at any time in Android Settings and can clear Vardely's local data by uninstalling the app. No information is uploaded to Vardely.

This policy describes the current version and must be updated if future versions add online services, advertising, analytics, or new permissions.

Contact: open an issue in the Vardely GitHub repository.
